# Product Core — PC-001

Status: IN DEVELOPMENT
Architecture: Prisma Growth Engine N3

## Objective

Provide transactional product registration and retrieval
using FastAPI and PostgreSQL.

## Scope

- Register a digital product
- Retrieve a product by UUID
- List products with pagination
- Enforce unique product slugs
- Require an administrative API key for writes
- Emit product.created using the transactional outbox
- Validate input using Pydantic
- Return meaningful HTTP errors

## Product Fields

- id: UUID, generated by PostgreSQL
- slug: unique lowercase URL identifier
- name: product display name
- audience: intended audience
- status: initial value draft
- created_at: timestamp
- updated_at: timestamp

## Supported Statuses

- draft
- prepared
- approved
- live
- paused

The archived status is deferred until a database migration.

## API Contract

POST /v1/products
GET /v1/products
GET /v1/products/{product_id}

### POST /v1/products

Requires X-Admin-Key.

Example:

{
  "slug": "precifica-facil",
  "name": "Precifica Fácil",
  "audience": "Pequenos comerciantes"
}

Success: HTTP 201 with persisted product.

Errors:
- 401: invalid or missing administrative key
- 409: duplicate slug
- 422: invalid payload

## Transactional Requirements

Product creation and product.created outbox insertion
must occur in the same database transaction.

If any operation fails, the entire transaction is rolled back.

The outbox records events but does not publish them yet.

## Out of Scope

- Product update and deletion
- Status transitions
- Offers management
- Product asset uploads
- Authentication for multiple administrators
- Checkout integration
- Automatic publication

## Acceptance Criteria

1. A valid product is persisted in PostgreSQL.
2. Duplicate slugs return HTTP 409.
3. Invalid payloads return HTTP 422.
4. Unknown product IDs return HTTP 404.
5. Writes require authorization.
6. Product creation emits exactly one outbox event.
7. Tests do not leave persistent test products.
8. Existing health checks continue to pass.
